AI Trend Scanner website

Files:
- index.html
- style.css

Free publishing option: GitHub Pages
1. Create a GitHub account if needed.
2. Create a new public repository, for example: ai-trend-scanner.
3. Upload index.html and style.css.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /root, then Save.
7. GitHub will provide a public URL you can use as the cTrader company website.

You can also host the same files with Netlify or Cloudflare Pages.
